# 第一章剧本包报告

## 交付范围

本包覆盖第 1 至第 7 游戏日，包含 12 个可消费节点，地点涵盖牧场、技术棚、牛羊区和鱼塘。节点使用 `id`、`scene`、`actor`、`trigger`、`lines`、`next` 或 `choices`、`fallback`、`recap` 契约。

## 运行接入

首轮运行时使用 `js/longform-story.js` 中的轻量首章切片。此 JSON 包作为后续系统接入 Agent 的正式输入，接入时需要把 `effects` 映射到 `state.js` 的关系、金币、章节和员工状态，并为旧存档增加默认值。

## 内容检查

- 节点 ID 唯一
- 每个节点都有错过文本和重玩文本
- 关键节点覆盖彤彤、牧心、周禾、林牧、沈露、许波、阿婆和员工群像
- 选择至少产生关系、金币或章节推进中的一项可观察结果
- 第七日通过两条选择都能进入第二章，不会锁死主线

## 后续扩写

继续按 `docs/large-version-blueprint.md` 的配额扩写对白、员工个人线、失败路线和日结文本。首章正文目标为 6,000 字，本包先提供结构完整的首轮节点，扩写后的正文仍需通过剧情字数和重复率门禁。
