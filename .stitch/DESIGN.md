# Design System: 牧场生活：共同体

## 1. Visual Theme & Atmosphere

这是一个有手工纸张质感的边境牧场界面。深绿承载地图和导航，奶油纸色承载任务、工具和故事，成熟麦穗金色负责行动焦点。画面像一册被反复使用的牧场手记，温暖、清楚、有生活痕迹。

界面密度保持在日常经营游戏的中等水平。地图始终是主角，HUD 只解释玩家当前需要做的事。弹窗、订单、员工和日结面板使用同一套纸张表面和分组结构。动效使用短促的位移、透明度和渐进出现来表达收获、工作和场景切换。

## 2. Color Palette & Roles

### Primary Foundation

- **深牧场绿** `#173B31` 用于应用外壳、地图下沿和主导航。
- **奶油纸面** `#FFF9EC` 用于故事、订单、员工和房屋面板。
- **浅麦纸** `#F1E6CB` 用于工具栏和可滚动内容底色。
- **结构线** `rgba(31, 67, 56, 0.14)` 用于分组边界和卡片轮廓。

### Accent & Interactive

- **成熟麦穗金** `#E9BD68` 是主要行动色，用于主按钮、选中工具、奖励、焦点环和重要进度。
- **河水青** `#6FAEB5` 只用于水量、海岛和钓鱼状态。

### Typography & Text Hierarchy

- **深墨绿** `#183C34` 用于正文和标题。
- **苔藓灰** `#6B7E70` 用于说明、次要状态和时间标签。
- **旧玫瑰** `#C87361` 用于失败、损坏和需要立即处理的状态。
- 不使用纯黑、霓虹紫和大标题渐变字。

## 3. Typography Rules

- 标题使用 `Nunito` 或 `Quicksand` 的 800–900 字重，中文回退到 `PingFang SC`、`Microsoft YaHei`。
- 故事正文使用 `DM Serif Text` 与中文宋体回退，行高 1.7–1.85。
- 数字、键位、时间和价格使用等宽字体，保持快速扫读。
- 交互标签至少 11px，正文至少 13px，移动端不低于 12px。小于 10px 的文字只用于装饰性英文眉题。
- 以 4px 为基础单位，常用间距为 8、12、16、24px。触屏按钮至少 44px 高。

## 4. Component Stylings

主按钮使用麦穗金平面填充和深绿文字，次按钮使用半透明纸面和细边框。按下时只做轻微位移和阴影收缩，不使用外发光。

卡片圆角保持 14–18px，使用轻薄结构线和柔和的深绿阴影。员工、订单、牲畜和房屋功能使用同一个“图标—标题—说明—操作”结构。世界导航使用横向滚动场景胶囊，选中态使用金色底和清晰文字。

地图 HUD 遵循“左上主线、右上反馈、底部工具”的三层结构。日结面板先给出当天结果，再给出工资、出货和明天提醒。野兽入侵使用警示横幅、波次和血条，避免用大面积红色覆盖地图。

## 5. Layout Principles

- 地图占据最大连续视觉区域，HUD 不遮挡玩家、目标和交互热点。
- 面板使用 CSS Grid 组织内容，宽屏采用主内容加辅助信息布局，窄屏降为单列。
- 视口断点覆盖 375、390、768、1024、1440px，移动端不得产生水平滚动。
- 页面使用 `min-height: 100svh`，工具栏和触控控件避让安全区。
- 弹窗最大高度为视口的 90%，正文独立滚动，底部操作始终可见。

## 6. Motion & Interaction

- 场景切换使用 260–420ms 的透明度与缩放过渡。
- 收获、播种、喂养、工资和奖励使用 180–360ms 的轻量反馈，动画只改变 `transform` 和 `opacity`。
- 员工工作动画与日结记录使用同一份状态数据。
- `prefers-reduced-motion: reduce` 时关闭循环粒子、缩放和延迟进入，只保留必要状态变化。
- 页面隐藏时暂停渲染和移动输入，回到页面后从零时间步继续。

## 7. Anti-Patterns

- 不使用纯黑、霓虹外发光、紫色渐变和大面积高饱和色。
- 不用虚构统计、与玩法无关的仪表盘或空泛宣传语。
- 不使用小于 44px 的主要触屏目标。
- 不让文字覆盖图片、地图角色或按钮。
- 不把失败写成没有恢复路径的“操作失败”。
