# SITE.md · 牧场生活：共同体

## 1. Core Identity

- **Project Name**: 牧场生活：共同体
- **Stitch Project ID**: `[Stitch Project ID]`
- **Mission**: 让玩家在一座边境牧场里亲自种植、照料牲畜、雇用员工、探索地图并推进关于水渠、劳动和牧心治理权的叙事。每个系统都回到具体劳动和可见的日结结果。
- **Target Audience**: 喜欢轻经营、叙事探索、角色关系和短局循环的网页游戏玩家，兼顾键鼠和移动端触屏用户。
- **Voice**: 温暖、具体、克制、有地方感。说明直接告诉玩家下一步，剧情保留人物的选择成本。

## 2. Visual Language

- **Primary vibe**: 手工纸张与深牧场绿
- **Secondary vibe**: 可靠的日常工具感
- **Tertiary vibe**: 雨后、河水、麦穗金和旧档案的时间痕迹

设计规范位于 `.stitch/DESIGN.md`，它是界面、动画和新增面板的视觉来源。

## 3. Architecture & File Structure

- `index.html` 承载首屏、HUD、Canvas、触控控件和弹窗容器。
- `css/style.css` 承载响应式视觉系统、组件状态和动效。
- `js/data.js` 承载作物、人物、建筑、场景、任务和商店配置。
- `js/state.js` 承载存档、日结、关系、员工、小游戏和经济规则。
- `js/renderer.js` 承载地图、天气、角色、动物、员工劳动和入侵动画。
- `js/game.js` 承载输入、UI、剧情编排、场景切换和保存。
- `js/minigames.js` 与 `js/minigame-layer.js` 承载可测试小游戏。
- `assets/manifest.json` 是静态资源清单与发布校验来源。

项目使用原生 HTML、CSS、ES Modules 和 Canvas。新增界面优先复用现有容器、状态服务和组件类名，不引入无必要的运行时依赖。

## 5. Roadmap Backlog

### High Priority

1. 保持首屏加载、继续游戏和新游戏按钮在资源未就绪时不可用。
2. 统一地图交互提示、工具选择、员工动作、日结和奖励反馈。
3. 维持 375px、390px、768px、1024px 和 1440px 下的可读性、触控尺寸和无横向滚动。
4. 对保存、重复点击、小游戏退出和页面隐藏恢复保持幂等与可恢复。
5. 每次发布运行 `npm run build`、`npm run story-paths` 和资源清单检查。

### Medium Priority

1. 为每个主要建筑补齐入口状态、当前功能和下一步提示。
2. 让员工劳动动作、日结摘要和生产数量始终来自同一状态记录。
3. 为战斗、钓鱼、种植和房屋活动提供一致的键鼠、触屏和减少动态体验。
4. 为季节、天气、员工关系和城市路线补充短事件，保持每天有一个可选目标。

### Low Priority

1. 将可复用的界面状态提炼为数据驱动配置，降低新增剧情和建筑的代码成本。
2. 增加可选的环境音层、场景主题变体和更多非关键视觉素材。
3. 生成 Stitch 设计快照，用于后续页面和面板的视觉回归。

## 6. Creative Freedom Guidelines

- 可以扩展角色服装、建筑细节、天气色调和地图装饰，但必须保留深绿、奶油纸、麦穗金三层视觉关系。
- 可以增加短事件和员工对话，但每段内容都要有可执行动作或可见结果。
- 可以使用 Canvas 画出地图专属动画，动画应服务于劳动、天气、动物和路线信息。
- 不能为了展示信息新增虚构统计、与经营无关的仪表盘或遮挡地图的装饰层。
- 任何新增按钮都要有禁用原因、触屏尺寸和键盘等价操作。
