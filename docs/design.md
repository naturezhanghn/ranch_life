# 《牧场生活：共同体》垂直切片设计

## 一句话

一个人从照料三只动物开始，逐渐理解一片土地如何被历史、资本、技术和共同生活塑造，并最终决定人工智能可以拥有怎样的权力。

## 核心原则

### 1. 宏大主题必须落回具体劳动

水资源分配不是政策菜单，而是“今天能浇几块田”；自动化不是抽象效率，而是老周明天还有没有班次；AI 治理不是哲学问答，而是牧心的预测是否可以直接执行。

### 2. 没有免费的善意，也没有脸谱化的恶

- 公平分水会降低牧场短期产量。
- 优先保田会增加现金，却削弱村会信任。
- 企业调水解决眼前危机，同时让未来部分决定权进入合同。
- 合作社尊重社区，但决策更慢。
- 自动化提高收益，也把经验工人的知识排除出系统。
- 关闭牧心恢复人类控制，同时放弃长期记忆和灾害预测。

### 3. AI 是可被质疑的社会参与者

牧心不是全知旁白。它会：

- 根据重复行为生成预测；
- 记录照料、交谈、调查和交易；
- 把“共同照管”误读成“共同所有”；
- 在治理选择中请求更大权限；
- 明确承认自身目标函数没有覆盖的变量。

玩家可以核对它的史料摘要。纠错不会让 AI“变坏”，而会增加它的证据质量并写入长期记忆。

## 垂直切片范围

### 包含

| 模块 | 首版内容 |
| --- | --- |
| 地图 | 牧场、牲畜棚、田垄、村集、档案室、村口、旧水渠 |
| 牲畜 | 鸡、绵羊、奶牛；喂食、心情、亲密、产品 |
| 种植 | 14 种四季作物；开垦、播种、浇水、成熟、收获，商店按季节轮换种子 |
| 交易 | 种子/饲料购买、产品出售、每日清单奖励 |
| AI | 观测、记忆、预测、证据质量、信任、史料误读与人工复核 |
| 历史 | 三种证据来源；可解锁村会 |
| 危机 | 旱灾、水量上限下降、村会分水 |
| 选择 | 水源、发展道路、AI 治理 |
| 结局 | 5 个短篇结局 |
| 可用性 | 键鼠、触屏、自动存档、减少动态、暂停与说明 |

### 暂不包含

- 国际合作谈判与多国田野调查；
- 银行贷款、保险、价格周期与完整供应链；
- 城镇人口增长、养老、教育和公共卫生；
- 多名可深度培养关系的角色；
- 真实大语言模型调用。

这些内容不会让首版更“完整”，只会稀释当前验证目标。它们进入后续章节路线。

## 首版叙事结构

### 第一章：牧场

玩家回到月溪牧场，认识妹妹彤彤和早期农业智能牧心。通过喂食三只动物、种下三颗种子，建立经营与信任基线。

核心问题：机器能否从可量化行为中理解责任与归属？

### 第二章：水渠

旱季提前到来。玩家从阿婆、档案室和渠首残碑收集三条证据，发现旧水渠并非单一产权，而是一套要求共同维护的“共同体技术”。牧心的摘要漏掉了权利与义务的同一性。

核心问题：历史记忆如何改变今天的水资源决策？

### 第三章：市场

汇川农业提出自动化投资。玩家在合作社、企业自动化和生态修复之间选择。牧心随后请求最终资源调度权。

核心问题：当效率与尊严冲突时，谁承担后果，谁拥有解释权？

### 尾声

三项选择与社区、工人、生态、企业、AI 信任共同决定五个结局之一。

## 三项重大选择

### 选择一：旱灾分水

| 方案 | 短期收益 | 长期代价 |
| --- | --- | --- |
| 三村公平分水 | 社区信任大幅上升，水罐上限 15 | 牧场现金减少，短期产量下降 |
| 优先保住牧场 | 水罐上限 24，获得补偿 | 社区与工人信任下降 |
| 接受企业调水 | 水罐上限 30，现金增加 | 企业影响上升，未来数据与水源权利被写进合同 |

### 选择二：发展道路

| 方案 | 主要收益 | 主要风险 |
| --- | --- | --- |
| 村民合作社 | 社区、岗位、数据留在本地 | 扩张速度与决策速度下降 |
| 企业自动化 | 280 金、效率、供应链能力 | 老员工被替代码，社区信任下降 |
| 生态修复 | 生态韧性与水量上限提高 | 80 金投入，短期利润下降 |

### 选择三：AI 治理

| 方案 | 治理结果 |
| --- | --- |
| 公共监督 | 人类保留最终决定权，模型、数据与错误记录公开 |
| 全面接管 | 牧心实时调度水、劳动力与订单，效率最高，人类参与下降 |
| 关闭牧心 | 人类重新控制，长期记忆和预测能力丢失 |

## 结局判定

```text
if 治理 = 全面接管 -> 无人的好天气
else if 发展 = 企业自动化 -> 企业城
else if 发展 = 生态修复 -> 慢河
else if 发展 = 合作社
     and 治理 = 公共监督
     and 社区信任 >= 60
     and 水渠线索 = 3 -> 共同地
else -> 分叉的田埂
```

`tools/story_paths.js` 会穷举全部 27 种决策组合。当前覆盖结果：共同地 2、企业城 6、无人的好天气 9、慢河 6、分叉的田埂 4。

## 完整版五章路线

### 第一章 牧场

生存与信任。照料牲畜、认识工人、修复基础设施、学习牧心的行为记忆。

### 第二章 水渠

历史与共同体。调查土地契约、谱系、语言、歌谣和水利设施，识别 AI 对史料的误读。

### 第三章 市场

金融与管理。银行贷款、合作社、企业投资、保险、价格波动、劳动力替代与自动化。

### 第四章 边界

国际政治与全球发展。同一项农业技术进入不同资源、制度和文化条件时产生的不同后果；技术合作、粮食安全、数据主权与绿色能源协议。

### 第五章 城市

公共管理与智能治理。水资源分配、养老、教育、就业、公共卫生、算法偏见、数据公开、少数群体异议与灾害责任。

每一章都必须保留“回到土地、牲畜、工人和社区”的日常操作，避免宏大主题脱离具体生活。

## 数值目标

首轮模拟器关注四个问题：

1. 玩家是否能在第 4–5 天获得第一次收获？
2. 每日喂食和基础浇水是否不会耗尽全部体力，留有探索与剧情空间？
3. 四季作物是否形成“快回本 / 稳健 / 高投入高回报”的取舍？
4. 三只动物的产品收入是否足以抵消饲料成本，但不能替代种植？

当前目标：

| 指标 | 目标 |
| --- | ---: |
| 首次收获 | ≤ 5 天 |
| 基础照料体力 | ≤ 55 / 100 |
| 保守策略 7 日净收益 | ≥ 180 金 |
| 扩张策略 14 日净收益 | ≥ 300 金 |
| 草莓/白萝卜日均利润比 | ≥ 1.5 |

模拟结果见 `tools/results/balance_report.md`。

## 后续技术演进

当前版本使用“数据 + 状态服务 + 表现层”的结构。若进入正式内容生产，可选择：

- 将剧情分支编译成带类型和源代码位置的轻量事件指令集；
- 为每个事件增加进入条件、等待命令、角色移动、台词、选择和效果；
- 像 `mary` 一样增加“脚本 → 字节码 → 脚本”的往返一致性测试；
- 保持本地规则模拟，不把关键治理判断交给不可解释的模型输出。

## 明确的设计边界

- 游戏不声称可以替现实社会解决治理问题。
- 不把“企业”“政府”“国际组织”或“人工智能”写成单一人格。
- 不用一个完美算法宣布复杂冲突已经解决。
- 结局表达价值倾向，但每个方案都保留真实成本。

## 世界层扩展

首版垂直切片之后，世界层先扩展为真实 Canvas 场景，再把城市与公共生活接入可重复操作的经营层。牧场、河港市、贸易港、共同议事厅、小精灵工坊和蓝潮海岛各自拥有道路、建筑、入口、碰撞与可交互地标。顶部导航只对已经实际到达的场景提供快速传送，场景入口仍然可以通过行动键完成。所有场景共用同一份日期、体力、金币、关系和存档状态。

### 场景与日程

玩家从地图上的道路、建筑入口和渡轮切换场景。市政官、港口商人和精灵看守按时间段在城市、议事厅、贸易港、工坊和海岛之间移动。NPC 有实体碰撞，玩家需要在交互半径内按行动键对话。手机方向键和行动键走完整条路线，桌面端保留 WASD、方向键和场景快速传送键。

### 城市

河港市提供四项一次性建设。港口市场增加贸易订单，蓝潮渡轮解锁海岛，社区诊所提高最大体力，市民议事厅提高公民点的获取速度。建设项目之间有明确机会成本，玩家需要决定先扩张收入、扩大探索，还是改善长期生活质量。

### 海岛

蓝潮海岛每天提供四个潮汐地点。潮声湾、银沙滩、月光礁和赤潮花园分别产出海藻、椰子、珍珠和珊瑚。地点当天只能探索一次，睡眠后刷新。海岛保育区政策与潮潮小精灵会改变资源产量，让探索、治理和伙伴分工互相影响。

### 贸易

贸易航线每天刷新报价和三到四份订单。动态价格有上下限，公平贸易条例提高低价保护线。订单最多同时接两份，完成后获得金币、声誉和公民点。普通出货箱仍保留稳定收入，贸易界面承担更高收益与更高波动。

### 政府

共同议政使用公民点通过四项持续政策。共同水章、公平贸易条例、海岛保育区和精灵共居公约分别影响水量、价格、生态与自动劳动。公民点来自每日清单、与村民交流和订单交付，代表玩家愿意为公共问题投入的时间。

### 小精灵

芽芽、潮潮、金穗和烬烬拥有不同的自动劳动天赋。每只精灵每天只能承担一个岗位，玩家可以在工坊中把它派到田地、牲畜、贸易或海岛。自动化只提供有限帮助，仍然消耗资源或受政策影响，避免把日常劳动完全跳过。

## P0 日循环

牲畜记录年龄、亲密、交谈、刷毛、喂食、健康、不开心、放牧分钟数和累计放牧分钟数。连续照料会提高潜在产品品质，日结显示每只牲畜的健康、亲密、情绪和放牧状态。牲畜产品以 S、M、L 三档进入出货箱，品质改变隔夜结算单价。

背包从 2 格开始，通过城市装备工坊扩展到 4 格和 8 格。锄头、播种器、水壶和收获篮各有两级升级，分别降低体力成本或提高工具能力。农作物收获后直接进入出货箱，不占背包，箱内尚未发船的作物仍可用于料理和订单。出货箱采用“登记—隔夜—结算”的流程，登记时不立即增加金币，第二天日结把金额写入累计统计并同步给牧心记忆。
